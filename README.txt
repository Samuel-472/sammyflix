SAMMYFLIX VERSION 4.0 - SEO + PLAYABLE ARCADE

FILES
- index.html: the website
- robots.txt: search engine crawling rules
- sitemap.xml: sitemap template

LOCAL TEST
1. Open this folder in VS Code.
2. Open index.html with Live Server.
3. Click Play Online in the top navigation.
4. Try Tic-Tac-Toe, Memory Match and Number Guess.

PUBLISHING AND SEARCH ENGINES
1. Upload the contents of this folder to a static web host (for example GitHub Pages, Netlify or Cloudflare Pages).
2. Obtain your public website URL/domain.
3. Replace YOUR-DOMAIN in sitemap.xml with that exact domain.
4. Uncomment and update the Sitemap line in robots.txt.
5. In the HTML, add a canonical URL and og:url using your final public URL.
6. Add the site in Google Search Console, verify ownership, and submit /sitemap.xml.
7. Submit the sitemap in Bing Webmaster Tools too.

IMPORTANT
- SEO tags do not make a local file appear in search results. SammyFlix must be published publicly first. Indexing can take days or longer and is not guaranteed.
- The arcade games are original browser mini-games that run on this page. GTA V, Minecraft, Forza Horizon and EA SPORTS FC remain links to their official publishers; they are not embedded or reproduced.
- This is still a frontend student project. Account data and favourites use browser storage. Do not collect real passwords or private information.
